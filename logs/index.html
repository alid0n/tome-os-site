Collect phone logs

Something not working right? Phone logs show what went wrong. This page saves them to a file on this computer with one click, over a USB cable. Nothing is uploaded: you choose whether to send the file to us.

This browser can't talk to phones over USB. Open tome-os.com/logs in Chrome or Edge on a computer.

  1. Turn on Developer options

    On the phone, open Settings › About phone and tap Build number 7 times. Enter your screen lock if it asks. It says "You are now a developer".Already done before? Skip this.

  2. Turn on USB debugging

    Go back to Settings › System › Developer options and turn on USB debugging. Press OK.

  3. Plug the phone into this computer

    With a USB cable, straight into the computer rather than a hub. Unlock the phone's screen.

  4. Press the button below, then tap Allow on the phone

    Pick the phone in the box your browser shows and press Connect. The phone asks "Allow USB debugging?": tick Always allow from this computer and tap Allow.

Save the logs

The file holds the phone's recent log and basic details: the model, the Tome OS version and the battery and storage state. It doesn't include your messages, photos, contacts or accounts, though app names and some settings can appear in it.

Stuck? Get help
    
Phone not in the browser's list? Check USB debugging is on and the phone's screen is unlocked. Unplug the cable and plug it back in. On Windows, install Google's USB driver.

    
Says another program is using the phone? Close Android Studio, or run adb kill-server, then try again.

    
"Allow USB debugging?" never shows? Unlock the phone. If it still doesn't show, go to Developer options, tap Revoke USB debugging authorizations, then try again.

    
Done? You can turn USB debugging off again in Developer options.
