Let your phone accept Tome OS

Phones only take a new operating system once you switch on a setting called OEM unlocking. It's hidden, so here's the trick. Try it on the practice phone, then do the same on your real phone.

  1. Open Settings › About phone
  2. Tap Build number 7 times
  3. Go back to Settings › System › Developer options
  4. Turn on OEM unlocking

Connect the phone to Wi-Fi, wait a minute, then look again. If it stays grey, the phone was locked by the carrier it was bought from (Verizon phones usually are), and Tome OS can't be installed on it.

Stuck? Get help with this step

Asked for your PIN? That's normal. Enter the phone's screen lock.

Can't find Developer options? Go back to About phone and tap Build number a few more times.

Phone already runs another custom OS, like LineageOS? OEM unlocking is already on. Skip this step.

Put the phone in install mode

Watch the practice phone, then do the same on yours. It's two buttons held together.

  1. Turn the phone off
  2. Hold Volume Down, then also hold Power
  3. Let go when you see an Android lying on its back
  4. Plug it in with the USB cable
Stuck? Get help with this step

Phone started normally instead? You let go too early. Turn it off and try again, holding both buttons until the Android appears.

Screen says "Fastboot Mode" in red? That's exactly right.

On Windows, if the next step can't find the phone, install Google's USB driver, then unplug the phone and plug it back in.

Install Tome OS

Press the button, then choose your phone in the box your browser shows. After that it runs by itself. It only needs you twice, to press buttons on the phone, and this page shows you which.

Waiting for the download to finish:

One thing first on Windows. Part way through, the phone switches to a second install screen, and Windows can't see it there without Google's USB driver. It takes about two minutes.

Everything on the phone is erased and replaced with Tome OS. This can't be undone.

  1. Connect to the phone
  2. Unlock it to accept Tome OS
  3. Install Tome OS
  4. Add Tome OS's key
  5. Check Tome OS starts
  6. Lock it again so it stays secure
