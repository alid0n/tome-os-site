Install Tome OS on the OnePlus Open

Tome OS replaces OxygenOS on the OnePlus Open: its home screen, settings and apps all go. What stays is the hardware layer OnePlus put underneath, the drivers and firmware that run the screens, camera and modem, which Tome OS's generic system image uses. It's installed with a few commands from a computer.

Experimental. Nobody has run Tome OS on a OnePlus Open yet. Install it on a phone you can do without for a while, and save your original software first.

Before you start

  • It needs OxygenOS 16. Check Settings › About device › Version starts with 16. If not, install OnePlus's updates first.
  • It erases the phone. Back up your photos, messages and anything else on it.
  • Calls and texts may not work where networks only have 4G and 5G, like most of the US: the parts that make calls over 4G and Wi-Fi are in OxygenOS, not the drivers Tome OS uses. Check this first if the Open is your everyday phone.
  • Other things may be missing at first: switching between the two screens when folding, the telephoto and OnePlus's camera modes, the Alert Slider, the fingerprint sensor, and higher refresh rates.
  • The bootloader stays unlocked, so the phone shows a warning as it starts, and new versions are installed the same way, by hand.

You need a computer with Google's Platform Tools (adb and fastboot), and a good USB cable.

0Save your original software

OnePlus doesn't offer a one-click way back, so make your own restore file while OxygenOS still runs. It's the only way back to OxygenOS later.

Save your original software

1Download Tome OS

The OnePlus Open's files aren't out yet. They'll be here as soon as they are.

Tome OS for the OnePlus Open:

Unpack the system image

The system image comes compressed (.img.xz). Unpack it here and it's checked against its checksum, or use xz -dk on a Mac or Linux, or 7-Zip on Windows.

Unpacking…

2Unlock the bootloader

This erases the phone. On the phone: Settings › About device › tap Version seven times, then Settings › System › Developer options › turn on OEM unlocking and USB debugging. Plug it in, then on the computer:

adb reboot bootloader
fastboot flashing unlock

Confirm on the phone with the volume keys and Power. It erases itself and starts OxygenOS again. Skip through setup and turn USB debugging back on.

3Switch verification off

From the folder with Tome OS's files:

adb reboot bootloader
fastboot flash vbmeta tome-os-<version>-gsi_arm64-vbmeta-disabled.img

Or use OxygenOS's own vbmeta from your restore file with fastboot --disable-verity --disable-verification flash vbmeta vbmeta.img. If the phone later stops at start with a verification error, do the same for vbmeta_system.

4Install Tome OS's system

Switch to fastbootd, the second fastboot screen, where the system can be written:

fastboot reboot fastboot
fastboot getvar is-userspace
fastboot getvar current-slot
fastboot snapshot-update cancel
fastboot flash system tome-os-<version>-gsi_arm64-system.img

is-userspace should say yes. If flashing says there isn't enough space, remove OxygenOS's product partition for the slot current-slot showed (Tome OS never uses it, and your restore file puts it back), then flash again:

fastboot delete-logical-partition product_a
fastboot flash system tome-os-<version>-gsi_arm64-system.img

Use product_b if the slot is b.

5Wipe and start

fastboot -w
fastboot reboot

The first start takes several minutes. If it keeps going back to the OnePlus logo, start the recovery (fastboot reboot recovery from fastbootd, or Power + Volume Down from off), choose Format data, and restart.

For a newer Tome OS later, repeat step 4. Your data usually stays; if the phone doesn't start, wipe it (step 5).

Going back to OxygenOS

Unzip your restore file. Then, with the phone in fastbootd (adb reboot fastboot):

fastboot snapshot-update cancel
fastboot flash system system.img
fastboot flash system_ext system_ext.img
fastboot flash product product.img

If you removed the product partition, make it again first with fastboot create-logical-partition product_a 1 (product_b for slot b). Then put verification back from the bootloader, wipe, and start:

fastboot reboot bootloader
fastboot flash vbmeta vbmeta.img
fastboot flash vbmeta_system vbmeta_system.img
fastboot flash vbmeta_vendor vbmeta_vendor.img
fastboot -w
fastboot reboot

Lock the bootloader again (fastboot flashing lock, which erases the phone) only once OxygenOS has started and works, and has installed an update from the phone, so both of its system copies hold OnePlus's software. Never install an OxygenOS older than the one the phone had.
