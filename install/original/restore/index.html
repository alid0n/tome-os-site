Go back to original software

This puts your OnePlus phone's original software back from the restore file this site saved before you installed Tome OS. It erases everything on the phone.

Not tried on a real phone yet. Until it has been, use it only if you're comfortable fixing a phone that doesn't start, and keep your restore file safe.

This needs a browser that can talk to phones over USB: open this page in Chrome or Edge on a computer.

1Choose your restore file

The zip this site saved, named like tome-original-CPH2551-….zip. Every part is checked against its checksum before anything is written.

Checking…

2Connect the phone in fastboot mode

  1. Turn the phone off. Then hold Volume Up + Volume Down + Power until the fastboot screen shows.
  2. Plug it into this computer, straight in rather than through a hub.
  3. Press the button and pick the phone. The page switches it to the second fastboot screen (fastbootd), where the system can be written, and asks you to pick it once more.

3Put the original software back

Starting…

Don't unplug the phone or close this tab until it says it's done.

4Check it starts

The phone restarts into its original software. The first start takes a few minutes. If it asks to format data or says it can't load Android, choose Format data or Factory reset.

5Lock the bootloader (optional)

Locking makes the phone as secure as new, and stops the warning at every start. A phone has two copies of its system, and both must hold OnePlus's own software first, or it won't start after locking.

  1. Set the phone up, connect to Wi-Fi, and install the update it offers in Settings › About device › Software update. If there's none, install the same full update you downloaded before, from that screen's menu (Local install). That writes OnePlus's software to the second copy.
  2. Let it restart and check it starts normally.
  1. Turn the phone off, hold Volume Up + Volume Down + Power for the fastboot screen, and plug it in.
  2. Press the button, pick the phone, and on the phone choose Lock the bootloader with the volume keys and press Power. Locking erases the phone once more.
