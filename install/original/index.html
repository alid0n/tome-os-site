Save your original software

Before installing Tome OS on a OnePlus phone, save the software it came with, so you can go back to it later. This page reads your phone's exact version, tells you which official update file holds it, and makes a restore file from it on this computer. Nothing is uploaded.

Got a Pixel? You don't need this. Google's Android Flash Tool puts the original software back on any Pixel.

This needs a browser that can talk to phones over USB and save large files: open tome-os.com/install/original in Chrome or Edge on a computer.

1Connect your phone

  1. On the phone, open Settings › About device, tap Version, then tap Build number 7 times.
  2. Go to Settings › System › Developer options and turn on USB debugging.
  3. Plug the phone into this computer and unlock its screen.
  4. Press the button, pick the phone, then tap Allow on the phone.
👉
Look at your phone and tap Allow.It asks "Allow USB debugging?". If nothing shows, unlock the phone's screen.

2Download the matching full update

Your original software is inside OnePlus's full update for exactly the version your phone runs. It's about 9 GB.

This asks roms.danielspringer.at, a public list of OnePlus updates, for your version. It sends only the model.

3Make your restore file

Choose the update you downloaded. This page checks it's the right one, takes out what's needed to go back, and saves it as one restore file. Have about 12 GB free on this computer while it saves.

Starting…

Keep this tab open. It takes a while: every part of your phone's software is unpacked and checked.

Keep both files somewhere safe, like an external drive or cloud storage. You'll need them to go back to your original software.

Carry on to install Tome OS

Details


  
Stuck? Get help
    
Phone not in the browser's list? Check USB debugging is on and the phone's screen is unlocked. Unplug the cable and plug it back in. On Windows, install Google's USB driver.

    
Says another program is using the phone? Close Android Studio, or run adb kill-server, then try again.

    
Your version isn't in the list, or the link won't download? OnePlus only lets its own apps download updates. The free OS Updater app (once called Oxygen Updater) can download the full update for your exact version: in its settings, choose your phone and the Full update method. Then copy the zip from the phone to this computer.

    
"That update is for a different version"? It must be the same version your phone runs now, not a newer one. If your phone has since updated, download the update for its new version.

    
Already installed Tome OS? The original software can't be read from the phone any more. Use the restore file you saved before.
