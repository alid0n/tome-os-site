Runes

Share a rune

Made a rune you love? Put it in the gallery so other people can use it too.

How to send it in

The gallery lives on GitHub, in the tome-os-site project. You share a rune by opening a pull request there. That's a request to add your files, which we read before saying yes.

  1. Write your rune

    A rune is a short text file that ends in .rune. The easiest start is a rune from the gallery: tap View code to see how it's written, then change what you like.

  2. Add it to runes/files

    Name the file after its id, like runes/files/ocean-calm.rune.

  3. Add it to the list

    Add an entry for it in runes/index.json, like the one below. The name, author and about should match the rune.

    {
  "id": "ocean-calm",
  "name": "Ocean calm",
  "author": "Tome OS",
  "about": "Deep sea blues, softer corners and a slow fade between tabs.",
  "file": "files/ocean-calm.rune",
  "kinds": ["colors", "motion"]
}

    For kinds, use colors if it has a theme, motion if it has a transition and blocks if it adds blocks.

  4. Open the pull request

    Say in a sentence or two what your rune does. If you can, add a screenshot of your Home screen with it on. If you have Python, run python3 runes/build.py to add your card to the page. If not, we'll do it.

What we check

A person reads every rune before it's listed. We look for these things:

  • No network. Runes can't go online anyway, and a rune shouldn't try.
  • Nothing hidden in scripts. A block's script should be short and easy to read, and do what its title says.
  • A clear name. The name and about say plainly what the rune changes. No names that copy someone else's.
  • Easy to read. Text has enough contrast with the colors behind it.

If something needs a change, we'll say so in the pull request. Once it looks good, we add it, and it shows up in the gallery a minute later.

No GitHub account?

That's fine. Email your .rune file to alid0ndev@gmail.com and we'll add it for you, after the same checks.
